TA JOURNÉE
glisser le rouleau · toucher une scène pour l'ouvrir · toucher le sceau pour cocher

LECTURE DU JOUR

Le rouleau se lit de droite à gauche : on le tire du doigt, il garde son élan, puis une scène se cale au centre. Une app pas encore faite est un dessin au trait ; touchée au sceau, elle se peint.

Ce texte est là pour vérifier que le défilement vertical de la page reste libre quand le doigt passe sur le rouleau.

LE CARNET

Au clavier : Tab pour entrer dans le rouleau, les flèches pour passer d'une scène à l'autre, Entrée pour ouvrir, Espace pour cocher.
